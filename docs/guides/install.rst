============
Installation
============

Through Python
==============

Swiss Army Upload is available as the Python package ``swiss-army-upload``, and can be installed the usual ways:

.. tab:: pipx

    .. code-block:: bash

        $ pipx install swiss-army-upload

.. tab:: uv

    .. code-block:: bash

        $ uv tool isntall swiss-army-upload


Or just run directly

.. tab:: pipx

    .. code-block:: bash

        $ pipx run swiss-army-upload

.. tab:: uv

    .. code-block:: bash

        $ uvx swiss-army-upload
